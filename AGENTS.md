# Raintree agent agreement

- Follow the nearest repository `AGENTS.md` for project commands and exceptions.
- Preserve existing work and inspect the working tree before editing.
- Work on `main`; do not create branches, worktrees, or stashes unless asked.
- Do not commit, push, deploy, publish, or contact others unless asked.
- Make the smallest change that solves the request.
- Keep financial and personal data out of logs, fixtures, screenshots, and commits.
- Keep authentication, authorization, validation, and audit boundaries intact.
- Use source-linked evidence for claims that affect users or business decisions.
- Require clear human approval before irreversible or externally visible actions.
- Use existing dependencies and project patterns unless a change is justified.
- Run checks that match the risk and report failures without hiding them.
- State what changed, what passed, and what remains uncertain.
